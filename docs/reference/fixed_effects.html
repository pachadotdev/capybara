fixed_effects {capybara}R Documentation

Extract fixed effects from a fitted model

Description

Accessor for the fixed-effect coefficients stored in a felm or feglm object, so that they can be retrieved without reaching into the model object's internal list structure (e.g. object$fixed_effects$dimension).

Usage

fixed_effects(object, which = NULL)

Arguments

object A felm or feglm object fitted with control = fit_control(return_fe = TRUE) (the default).
which Optional string with the name of a single fixed-effect dimension to extract (e.g. "exp_year"). If NULL (default), the full named list of fixed-effect vectors is returned.

Value

A named numeric vector (single dimension) or a named list of numeric vectors (all dimensions).

Examples

rose2004_subset <- rose2004[rose2004$year == 1999, ]
fit <- felm(ltrade ~ ldist | ctry1, rose2004_subset)

fixed_effects(fit, "ctry1")
